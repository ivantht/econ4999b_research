Replication of paper-style panel model: REER level response to geopolitical shocks

This report follows the panel-regression structure in doc/how GRP affect FX and capital flow.pdf, but uses repository shocks and screened countries.

Model used

y_it = β·GPR_it + γ'X_i,t-1 + φ'Z_t-1 + δ_i + ε_it

  • y_it: log real effective exchange rate, ln(REER_t), using BIS monthly real broad index.
  • GPR_it: repository shock proxy (event-month signed jump), including country-standardized proxy in paper-style specifications.
  • X_i,t−1: lagged domestic controls: log real industrial production, inflation, policy rate, debt-to-GDP, financial development.
  • Z_t−1: lagged global controls per paper style: log GEPU and log VIX.
  • δ_i: country fixed effects; SE clustered by country.
Missing-data handling: no rows are dropped for missing controls. Real industrial production from input/Real industrial production.csv is included, and missing controls are imputed using country-median (country controls) or global-median (global controls) values.
Alignment note: This run uses monthly BIS real effective exchange rate (real, broad basket). GPR_it remains the repository shock-episode proxy.
